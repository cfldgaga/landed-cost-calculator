计算说明

货物总价 = 产品单价 × 数量；关税 = 货物总价 × 关税率 ÷ 100。

总成本 = 货物总价 + 国际运费 + 保险费 + 关税 + 清关杂费 + 美国本地运费。

每件到岸成本 = 总成本 ÷ 数量。输入为空时按 0 处理；数量为 0 时，每件到岸成本显示为 0.00。计算保留中间精度，最终金额四舍五入显示两位小数。
